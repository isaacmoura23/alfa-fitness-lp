# Alfa Fitness · Landing page

Landing page estática da Academia Alfa Fitness (Ocara/CE): planos, horários, localização, avaliações e contato por WhatsApp.

- HTML, CSS e JS puros, sem build e sem dependências.
- Pasta raiz = site pronto para publicar (Vercel, Netlify, GitHub Pages).
- `vercel.json` traz os cabeçalhos de segurança.
- `DEPLOY.md` explica como trocar o domínio provisório `https://SEU-DOMINIO.vercel.app`.

Fotos da ficha pública da academia no Google Maps, com uso autorizado pelo responsável da academia.
